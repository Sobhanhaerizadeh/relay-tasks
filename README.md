## 🚀 What is Relay?

We're building an app for our team 🛠️

The idea is simple — imagine you have a task made up of **multiple steps**. Each person on the team takes their step, finishes it, and **passes the task forward** 🏃‍♂️➡️🏃‍♀️

On the dashboard you can instantly see:
- 👀 **Who's doing what** right now
- ⏳ **Who's waiting** on someone else
- 🚧 **Where things are stuck**

---

## ✨ Features

| | Feature | What it does |
|:---:|:---|:---|
| 🎯 | **Stage Ownership** | Every team member owns their step — no confusion about who's responsible |
| 🔄 | **Hand-off Flow** | Finish your part, pass it forward. The task keeps moving |
| 📊 | **Live Dashboard** | See the full picture in real time — progress, waits, and blockers |
| 🚧 | **Bottleneck Spotting** | Instantly find where work is stuck so the team can unblock it |
| ⚡ | **Fast & Lightweight** | Built on a snappy modern stack that just works |

## 🏁 Getting Started

### 📋 Prerequisites
- 🟩 [Node.js](https://nodejs.org/) (v18 or newer)
- 🐍 [Python](https://www.python.org/) (v3.10 or newer)
- 🌿 [Git](https://git-scm.com/)

### 📦 Installation

```bash
# Clone the repo
git clone https://github.com/Sobhanhaerizadeh/relay-tasks
cd relay-tasks
```

**⚛️ Frontend**
```bash
cd frontend
npm install
npm run dev
```

**🐍 Backend**
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

> 💡 Once both are running, open your browser and the relay begins!
